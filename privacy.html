Health Assistant — Privacy Policy

Last updated: 2026-10-27

English

Health Assistant is a private application used by a single person, its owner. With the owner's consent it reads the owner's Google Health data (activity, sleep, health metrics) in read-only mode, solely to produce personal analysis and recommendations delivered via Telegram.

  • Data is stored on the owner's private server and is not sold, shared or used for advertising.
  • To generate answers, relevant data is processed by the OpenAI API acting as a processor.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time at myaccount.google.com/permissions; stored data is deleted on the owner's request.

Русский

Health Assistant — личное приложение одного пользователя (владельца). С его согласия оно в режиме только чтения получает данные Google Health владельца (активность, сон, показатели здоровья) исключительно для персонального анализа и рекомендаций в Telegram.

  • Данные хранятся на частном сервере владельца, не продаются, не передаются третьим лицам и не используются для рекламы.
  • Для формирования ответов нужные данные обрабатываются через OpenAI API.
  • Доступ можно отозвать в любой момент: myaccount.google.com/permissions.
